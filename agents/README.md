# Agents

Agent definitions — the role, tools, and behavior that shape an autonomous or semi-autonomous assistant.

## What belongs here

Descriptions of an agent's purpose, when it should be used, the tools it needs, and how it should behave.

## Shape

One Markdown file per agent, named in `kebab-case` (e.g. `code-reviewer.md`). Begin with a heading naming the agent and a one-line summary, then cover its role, the tools or capabilities it relies on, and its operating instructions. Keep it portable across providers where possible.
