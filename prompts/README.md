# Prompts

Standalone prompts and prompt templates ready to copy into your own setup.

## What belongs here

Single-purpose prompts — system prompts, task prompts, or reusable templates with placeholders to fill in.

## Shape

One Markdown file per prompt, named in `kebab-case` (e.g. `summarize-meeting-notes.md`). Start the file with a short heading that states what the prompt is for and what inputs it expects. Mark fill-in slots clearly, for example `{{topic}}` or `[PASTE TEXT HERE]`.
