# Snippets

Small reusable fragments — the building blocks you drop into larger prompts or agents.

## What belongs here

Short, composable pieces: system blurbs, formatting rules, tone guidelines, few-shot examples, or any fragment you find yourself reusing.

## Shape

One Markdown file per snippet, named in `kebab-case` (e.g. `json-only-output.md`). Open with a one-line note on what the fragment does and where to paste it. Keep each snippet focused on a single idea so it stays easy to mix and match.
